## 들어가며

오늘은 CSS 선택자를 기본 선택자부터 속성 선택자, 계층(자손·후손) 선택자, 형제 선택자, 구조 선택자까지 실습했다. CSS 코드를 공부할 수 있도록 만든 게임을 풀면서 `.`은 **class**, `#`은 **id**를 가리킨다는 걸 확실히 익혔다. 다만 `+` 연산자와 `:first-child`, `:last-child` 같은 선택자는 아직 헷갈려서, 나중에 상황별로 찾아볼 수 있도록 **예시 코드와 함께 표**로 정리해둔다.

## 1. 기본 선택자

| 선택자 | 문법 | 의미 | 예시 |
|---|---|---|---|
| 전체 선택자 | `*` | 문서 안의 모든 요소 선택 | `* { color: red; }` |
| 태그 선택자 | `태그명` | 해당 태그를 모두 선택 | `li { color: blueviolet; }` |
| id 선택자 | `#id값` | 문서에서 유일한 특정 요소 하나 선택 | `#id3 { color: green; }` |
| class 선택자 | `.class값` | 같은 class를 가진 여러 요소 선택 (재사용 가능) | `.class3 { color: chartreuse; }` |

> `.`은 class, `#`은 id와 연결된다는 걸 코드 게임을 여러 번 풀면서 헷갈리지 않게 됐다.

## 2. 속성 선택자

특정 속성이나 속성값을 기준으로 요소를 선택한다. `선택자[속성명=속성값]` 형태로 쓴다.

| 문법 | 의미 | 예시 |
|---|---|---|
| `[속성=값]` | 속성값이 정확히 일치하는 요소 | `div[name=name2]` |
| `[속성~=값]` | 공백으로 구분된 값들 중 하나로 포함하는 요소 | `div[name~=name1]` |
| `[속성|=값]` | 값과 정확히 일치하거나, 값 뒤에 `-`가 바로 붙어 시작하는 요소 | `div[class|=class]` |
| `[속성^=값]` | 값으로 **시작**(접두사)하는 요소 | `div[name^=name]` |
| `[속성$=값]` | 값으로 **끝나는**(접미사) 요소 | `div[class$=class]` |
| `[속성*=값]` | 값을 **포함**하는 요소 | `div[class*=div]` |

## 3. 계층 선택자 (자손 / 후손)

| 선택자 | 이름 | 의미 | 예시 |
|---|---|---|---|
| `부모 > 자식` | 자손 선택자 | 바로 한 단계 아래에 있는 요소만 | `#test1 > h4` |
| `조상 후손` | 후손 선택자 | 하위에 있는 요소를 전부 (몇 단계든) | `#test1 ul` |

## 4. 동위(형제) 선택자 — `+`, `~`

오늘 배운 것 중 **가장 헷갈렸던 부분**이다. 둘 다 "형제 관계"를 다루지만 범위가 다르다.

| 선택자 | 의미 | 예시 |
|---|---|---|
| `A + B` | A 바로 다음에 오는 형제 B **딱 하나만** | `#div-test1 + div` |
| `A ~ B` | A 뒤에 오는 형제 B를 **전부** | `#div-test1 ~ div` |

**기준: `+`는 "바로 다음 1개", `~`는 "뒤에 있는 전부"** 라고 구분해서 외우니 헷갈림이 줄었다.

## 5. 구조 선택자 — `nth-child` 계열

형제 요소들 사이에서 **몇 번째 위치**인지로 선택하는 선택자. 이것도 헷갈렸던 부분이라 예시를 꼭 붙여둔다.

| 선택자 | 의미 | 예시 |
|---|---|---|
| `:first-child` | 형제 중 첫 번째 요소 | `#test :first-child` |
| `:last-child` | 형제 중 마지막 요소 | `#test :last-child` |
| `:nth-child(n)` | 형제 중 n번째 요소 (`n`에 숫자를 직접 대입) | `:nth-child(2)` → 2번째 요소 |
| `:nth-child(2n)` | 짝수 번째 요소 | `:nth-child(2n)` |
| `:nth-child(odd)` | 홀수 번째 요소 (`2n-1`과 동일) | `p:not(:nth-child(odd))`에서 사용 |
| `:nth-last-child(n)` | **뒤에서부터** n번째 요소 | `:nth-last-child(4)` |

## 6. 반응 / 상태 선택자

사용자의 행동이나 입력 요소의 상태에 따라 적용되는 선택자다.

| 선택자 | 의미 | 예시 |
|---|---|---|
| `:hover` | 마우스를 올렸을 때 | `#hover-test:hover` |
| `:active` | 클릭(누르는 중)했을 때 | `#active-test:active` |
| `:focus` | 입력창이 포커스를 받았을 때 | `#userId:focus, #userPwd:focus` |
| `:checked` | 체크박스/라디오가 선택됐을 때 | `input[type=checkbox]:checked` |
| `:enabled` | 사용 가능한(활성화된) 요소 | `option:enabled` |
| `:disabled` | 사용 불가능한(비활성화된) 요소 | `option:disabled` |

## 7. 부정 선택자 & 문자 선택자

| 선택자 | 의미 | 예시 |
|---|---|---|
| `:not(조건)` | 조건에 해당하지 **않는** 요소 | `#test2 p:not(:nth-child(odd))` → 짝수 번째만 |
| `::selection` | 사용자가 마우스로 드래그해서 선택한 부분 | `#test3 p::selection` |
| `::first-letter` | 텍스트의 첫 글자 | (실습에서는 주석 처리해서 보류) |
| `::first-line` | 텍스트의 첫 줄 | (실습에서는 주석 처리해서 보류) |

## 8. CSS 작성 방식: 내부 스타일 vs 외부 스타일시트

| 방식 | 작성 위치 | 특징 |
|---|---|---|
| 내부 스타일 | `<style>` 태그 안 (head 영역) | 한 파일 안에서 바로 확인 가능하지만, 다른 페이지와 공유하기 어려움 |
| 외부 스타일시트 | 별도의 `.css` 파일 + `<link rel="stylesheet" href="파일명.css">` | 여러 페이지에서 재사용 가능하고 유지보수가 편함 |

## 마무리

오늘은 코드로 만든 게임을 풀면서 `.`(class)과 `#`(id)의 역할을 확실히 구분하게 된 게 가장 큰 수확이었다. 반면 `+`/`~` 형제 선택자와 `:first-child`/`:last-child`/`:nth-child` 같은 구조 선택자는 범위와 순서를 헷갈리기 쉬워서, 이번 글은 **예시 코드가 딸린 표**로 정리해뒀다. 나중에 비슷한 상황을 만나면 이 글을 백과사전처럼 찾아보면서 바로 활용할 계획이다.
