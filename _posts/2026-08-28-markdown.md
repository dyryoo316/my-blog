## 오늘 배운 것

Git은 **저장 지점을 남기고 되돌릴 수 있게** 해주는 도구다.

### #개수와 글씨 크기
'#'의 개수가 늘어날수록 글씨가 점점 작아진다.
'#', '##', '###'가 있다.

### 굵은 글씨와 기울여 쓰기
굵게 하고자 하는 글씨의 앞뒤에 '**'를 붙인다
기울이고자 하는 글씨의 앞뒤에 '*'를 붙인다
예) **굵은 글씨**와 *기울어진 글씨*

### 순서가 없는 목록 만들기
'-'와 '*'를 사용한다
Tab을 사용해 하위목록을 만들 수 있다
예)
- 첫 번째
- 두 번째
* 세 번째
* 네 번째
    * 4-1. 번째

### 순서가 있는 목록
숫자와 .을 함께 적어 주면 된다
예)
1. 하나
2. 둘

### 링크를 첨부하는 방법
[링크설명](링크)
예)
* [나의 깃허브] (https://github.com/dyryoo316)

### 이미지를 첨부하는 방법
!['이미지 설명']('파일명')
예)
* ![고양이 사진](cat.jpg)

### 인용하는 구문
인용하는 구문은 꺽쇠로 만든다.
남의 말이나 정의를 옮길 때 사용한다.
예)
> 인용하는 구문은 꺽쇠로 만든다.
> 남의 말이나 정의를 옮길 때 사용한다.

### 백틱과 코드블록
* ` 은 1옆에 있는 것으로 "백틱"이라고 명칭한다.
* 백틱 내부에는 코드, 명령어를 입력하게 된다.
예)
```
git status
git init
```


### 마크다운 문법으로 표 만들기
 '|' 표시는 개발쪽에서는 OR 연산자라고도 부른다.
 ENTER 키 위에 존재한다.

|명령어|하는 일|
|---|---|
|git add|스테이징 영역에 파일 추가|
|git commit|로컬 저장소에 저장|
